The code did change, but it was not a single versioned program:

1. **Earliest saved family fallback, June 20 01:31:12:** `/oecd-equity-r5-live/COUNTRY/up`; the country is already encoded in the key. Shared `R4-Slovak` and `R5-Slovenia` keys follow.
2. **After test contamination:** new `R4OBSERVED-SLOVAK`, `R4ACTUAL-JUN20-LATE`, and individual cohort namespaces distinguish fresh actual-prompt events from old/test records.
3. **Per-cohort event and continuation flags:** `R4-ACTUAL` or `R4-SEEN`, plus `R5-SCHEDULED` if another round is announced. Feb19 #1 and Oct07 #1 start this way.
4. **Explicit country disambiguation:** add `R4-SLOVAK` (Oct07: `R4-SLOVAK-CONFIRMED`) versus `R4-OTHER`, alongside the generic flag. Jul24 #7 repairs shell-damaged URLs; Apr14 #8 adds the missing URL prefix. The final saved exchanges retain this paired convention.
